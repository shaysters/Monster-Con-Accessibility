# Monster Con Accessibility 1.1.4

Run **MonsterConAccessibilityInstaller.exe** to install or update. Close the game first. You can still install by hand from the zip; see the README.

## Changes

- When the title menu has been read, the mod tells you if a newer version is out, without cutting off what's being read. Run the installer to update.
- The installer accepts GOG and DRM-free copies of the game. It doesn't find them by itself, so use Browse to pick the game folder. The mod has only been tested with the Steam version, and the installer says so.
- The README has been reorganized, with installer, manual and developer instructions, and links to the Discord and Ko-fi.
