# Monster Con Accessibility 1.1.3

Run **MonsterConAccessibilityInstaller.exe** (or the one you already have) to install or update. Close the game first. You can still install by hand from the zip; see the README.

## Fixed

- The online code is read reliably when you host a match. Press C in the lobby to hear it again.
- Food court table names are read on controller focus too, not only when focus lands on the table's button.
