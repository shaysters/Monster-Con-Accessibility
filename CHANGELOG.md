# Changelog

## 1.1.4 - 2026-10-31

### Added
- When the title menu has been read, the mod tells you if a newer version is out. Run the installer to update.

### Changed
- The installer accepts GOG and DRM-free copies of the game. It doesn't find them by itself, so use Browse to pick the game folder. The mod has only been tested with the Steam version, and the installer says so.

## 1.1.3 - 2026-10-30

### Fixed
- The online code is read reliably when you host a match.
- Food court table names are read on controller focus too, not only when focus lands on the table's button.

## 1.1.2 - 2026-10-30

### Added
- Standalone installer (MonsterConAccessibilityInstaller.exe). It installs BepInEx if needed, then the mod, and can update, repair, or uninstall.
- When you host an online match, the online code is read digit by digit. Press C in the lobby to hear it again.
- Food court tables say who is sitting there and how many seats are free.

### Changed
- Speech goes through Prism instead of Tolk and direct NVDA: screen readers, braille displays, or built-in Windows speech when no screen reader is running.

## 1.0.0 - 2026-05-06

- First release.
